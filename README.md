# Reynard Default Browser iOS 14

Opens browser links in Reynard on rootful iOS 14. Confirmed working on iOS 14.3.

- Enable or disable it in Settings or Control Centre.
- Enabled by default.
- No respring needed when changing the toggle.

Download the `.deb` from [Releases](https://github.com/551UK/Reynards-Default-Browser-iOS14/releases/latest), install it, then respring once.

Requires Reynard, PreferenceLoader and CCSupport.

The was someone who offered an iOS 14 version of this same concept, but it did not work correctly on the iOS 14.3 device tested here. This separate rootful build fixes the link-opening problem and is confirmed working.
